# byteutils-rs

Safe Rust port of the endian and NTP timestamp helpers in `lib/byteutils.c`, with isolated C ABI wrappers that retain the original export names. Slice APIs report out-of-range offsets rather than reading invalid memory.

The C reference vectors in `reference-vectors.tsv` were generated by compiling the untouched source with `units/byteutils/.rust-anything/reference.c` using MSYS2 UCRT64 GCC 16.2.0 on Windows x86_64. The fixture covers all ten exported helpers over five fixed byte patterns and varied offsets. `lib/byteutils.c` SHA-256: `E69BFB90DE3A5865A1475D481B8D19BF582D8301E537F4C3EA0E12A774D40519`. The original source explicitly assumes a little-endian CPU; the Rust implementation uses little-endian conversions for those host-order helpers and explicit big-endian conversions for network fields. The linked smoke test compared the Rust DLL against the original C object for every getter and setter.

Run the crate checks from this directory:

```powershell
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --all-targets
```
