# hand-garble-rs

Rust port of `hand_garble.c`, bridged with the C ABI. Generated by rust-anything.

The fixed-size `garble()` Rust API models C `unsigned int` modulo arithmetic explicitly, so results do not depend on Cargo's overflow-check profile. All five output buffers match the C routine across 256 deterministic inputs, including when this crate is built as a dependency with overflow checks enabled. The generic C ABI gate covers the three scalar exports (135/135); `garble()` is a safe array API because the source bridge cannot model its pointer ownership.
